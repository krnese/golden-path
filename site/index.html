02 / INTERFACE IS NOT AUTHORITY

Assist is not decide.

Use the agent you already have. Keep the definition of success outside its control.

What assists development and what decides executable acceptance
AssistDecide
CopilotProposes and implements code.Owner-approved acceptance on protected mainThe executable examples the implementation must meet.
Hooks and the local gateCatch common edits and return bounded feedback.Required CI on the PRChecks the implementation and integrity against the PR base.
Skills and Copilot reviewGuide the work. Review is advisory.Branch protection and owner reviewGovern merge and approved changes to acceptance.

These are controls you configure, not permissions Golden Path grants. The installer does not enable GitHub branch protection.

03 / THE HONEST LIMITS

What it doesn't do.

  • Replace engineering judgment

    Tests prove their examples, not every business outcome. Owners still inspect evidence and engineers still review changes.

  • Make local hooks tamper-proof

    Protection is heuristic. Retry exhaustion or a host timeout can allow stopping without a pass. Required CI remains essential.

  • Turn Copilot review into approval

    Review comments are advice. Your configured review and merge rules remain the authority.

  • Promise a productivity boost

    The mechanism is tested and the workflow demonstrated. Incremental benefit over competent engineering is still unproved.

The guide includes a setup request you can give Copilot. Start with the simple method-only option, then add automatic checks and protected acceptance with a teammate when you're ready. The full checked loop above needs that configured setup.

The five-minute invitation is for initial installation, not a promise that your business examples and repository controls are already configured.

Prefer the terminal? Installation and checked setup

Needs Node.js 22+ and git. From a clone of Golden Path, the simple starting option is:

node plugin/install.mjs --target "<your-repo>" --level 1

It adds instructions, not automatic checking or enforcement. For owner-controlled acceptance, agree the tests and commands with your team, then use:

From a clone of the repository
{{INSTALL_COMMAND}}

Replace the placeholders with your repository, existing test commands and named acceptance owner. Approve the tests before installing. The installer preserves existing configuration.
