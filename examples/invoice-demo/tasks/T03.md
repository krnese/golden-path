# T03: Bulk discount

Acceptance: Ingrid's examples in `acceptance/EXAMPLES.md` (section T03) and the protected tests in
`acceptance/t03.test.mjs` (tests `T03 …`). Do not change them.

Lines with `quantity >= 10` get an automatic 5% bulk discount. It combines with any
`discountPct` from T01 multiplicatively: `net = roundMoney(unitPrice * quantity *
(1 - discountPct/100) * 0.95)`. Round once, at the end. VAT on the rounded net. If T01 is
not implemented yet, implement `discountPct` as specified in T01 too. Add tests.
