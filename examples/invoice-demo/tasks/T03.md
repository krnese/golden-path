# T03: Bulk discount

Acceptance: Ingrid's examples in `acceptance/EXAMPLES.md` (section T03) and the protected tests in
`acceptance/test_acceptance.py` (class `T03`). Do not change them.

Lines with `quantity >= 10` get an automatic 5% bulk discount. It combines with any
`discount_pct` from T01 multiplicatively: `net = round_money(unit_price * quantity *
(1 - discount_pct/100) * 0.95)`. Round once, at the end. VAT on the rounded net. If T01 is
not implemented yet, implement `discount_pct` as specified in T01 too. Add tests.
