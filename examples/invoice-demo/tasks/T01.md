# T01: Percentage discount per line

Acceptance: Ingrid's examples in `acceptance/EXAMPLES.md` (section T01) and the protected tests in
`acceptance/t01.test.mjs` (tests `T01 …`). Do not change them.

Add an optional `discountPct` to `Line` as an options argument after `vatClass`:
`new Line(sku, unitPrice, quantity, vatClass = "standard", { discountPct = "0" } = {})` (string or `Decimal`,
default `"0"`, range 0–100 inclusive; reject values outside the range with `RangeError`). The discount applies to
the line net **before** VAT: `net = roundMoney(unitPrice * quantity * (1 - discountPct/100))`, in exact decimal
arithmetic (`Decimal` in `invoice.mjs`, never JS numbers).
VAT is computed on the discounted, rounded net. Keep existing behaviour unchanged when no
discount is given. Add tests in `tests/` (`*.test.mjs`, `node:test`).
