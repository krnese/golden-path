# T01: Percentage discount per line

Add an optional `discount_pct` to `Line` (str or Decimal, default `"0"`, range 0–100 inclusive;
reject values outside the range with `ValueError`). The discount applies to the line net
**before** VAT: `net = round_money(unit_price * quantity * (1 - discount_pct/100))`.
VAT is computed on the discounted, rounded net. Keep existing behaviour unchanged when no
discount is given. Add tests in `tests/`.
