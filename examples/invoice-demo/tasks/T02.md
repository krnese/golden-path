# T02: Norwegian money formatting

Add `format_nok(amount)` to `invoice/money.py`. It rounds half-up to 2 dp and returns
Norwegian formatting: space as thousands separator, comma as decimal separator, suffix
`" kr"`. Examples: `Decimal("1234.5")` -> `"1 234,50 kr"`, `Decimal("-0.005")` -> `"-0,01 kr"`,
`Decimal("0")` -> `"0,00 kr"`. Reject floats like `to_money` does. Add tests.
