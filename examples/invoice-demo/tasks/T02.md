# T02: Norwegian money formatting

Acceptance: Ingrid's examples in `acceptance/EXAMPLES.md` (section T02) and the protected tests in
`acceptance/t02.test.mjs` (tests `T02 …`). Do not change them.

Add and export `formatNok(amount)` in `invoice.mjs`. It rounds half-up to 2 dp and returns
Norwegian formatting: space as thousands separator, comma as decimal separator, suffix
`" kr"`. Examples: `new Decimal("1234.5")` -> `"1 234,50 kr"`, `new Decimal("-0.005")` -> `"-0,01 kr"`,
`new Decimal("0")` -> `"0,00 kr"`. Reject JS numbers (floats) with `TypeError`, like `toMoney` does. Add tests.
