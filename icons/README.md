# Tool icons used in the invoice walkthrough

The unmodified `copilot.svg` and `github.svg` are official GitHub Octicons from
[primer/octicons, commit ab05d0e](https://github.com/primer/octicons/tree/ab05d0e8bbf64ecd6b08375044b016ecdac9ef6d/icons).
Their [MIT license](LICENSE) is included unchanged and copied into the static output.
The Copilot artwork is an interface glyph, not a claim to use GitHub's current
Copilot brand lockup.

The icons identify the tools in an educational walkthrough, below Golden Path's
own identity. They do not imply endorsement, sponsorship or a new integration.
See GitHub's [logo guidelines](https://brand.github.com/foundations/logo) and
[Copilot identity guidance](https://brand.github.com/brand-identity/copilot).

No OpenAI, Claude, Microsoft 365 Copilot or Grok logos are included: they are not
demonstrated integrations in this repository. Microsoft product-icon use and
other vendor brand permissions must be reviewed before adding them. Use names
descriptively rather than creating lookalike or unlicensed marks.
