# Engineering with Golden Path

Before acting on engineering work, read the bundled
[Golden Path method](references/golden-path/METHOD.md). It owns the procedure:
Understand -> Bound -> Engineer -> Prove -> Report.

Apply it to the actual request using existing repository instructions,
requirements, designs, tests, review and operating evidence. The method grants
no authority and does not replace project or organizational controls.

Continue permitted work without unnecessary approval. Surface a consequential
change rather than silently expanding the assignment. Use the optional agreement
template only when equivalent authoritative information is missing.

Use the existing Copilot tools and reasoning loop. Do not create another agent,
ledger or mandatory document merely to apply this method. Report real verification,
remaining uncertainty and decisions needed; do not invent successful checks.
