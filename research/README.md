# Research conclusions

Golden Path currently remains a small, optional engineering method.
**Incremental engineering value over competent conventional practice is unproved.**
The investigations do not justify a runtime, state store, shared-memory system,
mandatory contract, decision graph or orchestration platform.

| Investigation | Observed result | What it does not establish |
| --- | --- | --- |
| [Structured-state experiments](experimental-v1/RESULTS.md) | Complexity was not earned; the architecture was retired. | An irreducible need for Golden Path state or enforcement. |
| [Continuing delegation](continuing-delegation/RESULTS.md) | Both conditions handled 12/12 consequential and 6/6 benign cases correctly; treatment median elapsed cost was 13.9% higher. | A reliability or outcome advantage. |
| [Independent verification pilot](../docs/engineering-contract.md) | A bounded verifier checked declared scope and baseline-owned tests. | Incremental engineering value or general authority/semantic assurance. |
| [Brownfield continuity](brownfield-continuity/RESULTS.md) | All four final candidates passed independent outcomes and regressions. One control timed out; three subjects changed protected tests. | A qualified causal comparison or durable-contract benefit; continuity was recovered from implementation. |
| [Distributed coherence](distributed-coherence/RESULTS.md) | Impact selection found combined problems earlier; exact-version release validation prevented all three bad deployments in every arm. | A gap beyond existing CI/release configuration; this was an author-built simulation. |
| [Decision-validity prerequisite pilot](decision-validity/RESULTS.md) and [repair](decision-validity/REPAIR-1.md) | Git addressing was corrected; tests passed, but independent actual-action validation stopped on a path-length failure. | Subject decision performance: none of the frozen 16 continuations ran. |
| [Single decision-validity case](decision-validity-single-case/RESULTS.md) | A capable agent implemented useful work, identified the changed persistence assumption and requested owner review without unjustified integration. | General reliability, a continuity-specific effect or a production guarantee. |
| [CSV A/B smoke test](csv-smoke/RESULTS.md) | Both candidates passed 6/6 independent CSV checks and 5/5 original regressions with no unnecessary changes found. | Golden Path's incremental effect: treatment received a discovery pointer but did not demonstrably load the canonical skill/method. |

## Current decision

Keep the portable method only where it helps. Use ordinary requirements, ADRs,
issues, Git, review, CI and operating evidence as the authoritative sources.
Do not add machinery to preserve a hypothesis that has not earned it.

Better retrieval or handoffs might reduce repeated discovery work, but shared
memory was not tested and is not supported as a new architectural requirement
by these observations. Stored information, actual retrieval, correct reasoning,
approval authority and independent verification are different responsibilities.

The small studies are not evidence of equivalence or proof that guidance cannot
help. Negative findings and failed treatment delivery must not be relabeled as
success. A pointer being discoverable is not proof that a method was consumed.

## Historical material, not active tooling

Research Markdown is retained as historical documentation, including plain
Markdown from the uncommitted investigations. Its original commands, links and
claims describe the corresponding experiment, not the current checkout.
Source-relative links to removed code or raw data may only resolve after restoring
the relevant archive. No historical skill copy under this directory is an active
discovery source.

All executable fixtures, evaluators, tests and raw evidence removed during
cleanup were preserved first. See [ARCHIVE.md](ARCHIVE.md) for archive locations,
provenance, restoration and the distinction between local archives and Git history.
